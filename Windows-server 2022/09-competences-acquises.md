# Compétences acquises

## Présentation

La réalisation de ce laboratoire a permis de développer des compétences pratiques en administration systèmes et réseaux.

L'objectif n'était pas uniquement de mettre en œuvre une infrastructure fonctionnelle, mais également de comprendre les mécanismes sous-jacents ainsi que les méthodes de diagnostic et de résolution d'incidents.

# Méthodologie de diagnostic

Les différents incidents rencontrés m'ont permis d'acquérir une démarche structurée :

1. Identifier le symptôme ;
2. Formuler des hypothèses ;
3. Tester les hypothèses ;
4. Isoler la cause ;
5. Appliquer une correction ;
6. Vérifier le résultat.
